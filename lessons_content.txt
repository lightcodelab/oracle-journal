               |                                                            |             | You can name the childhood pattern.                |                                                            |             |                                                                                                                                                                                                                                                                                                                                                                                                                          +
               |                                                            |             | This does not mean you have failed to heal.                |                                                            |             |                                                                                                                                                                                                                                                                                                                                                                                                                          +
